# ESP32 CPS Firmware

This directory is the current implementation area for firmware used by the final Sentinel-CPS ESP32 CPS testbed.

The final architecture uses Gateway-mediated Wi-Fi communication between the Raspberry Pi 4 Sentinel Gateway and one ESP32 CPS.

Earlier Hub, ESP-NOW, serial-protocol, and vehicle-oriented firmware is preserved under `archive/pre-refocus/` as historical development material.

Final firmware will be added here as implementation is reconciled with the documented Wi-Fi workflow.
